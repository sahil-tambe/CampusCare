Registration rules
1. Users must register using an email ending in @somaiya.edu.
2. Personal Gmail accounts will not be accepted.
3. Firebase sends an email verification link.
4. Users must verify their email before accessing the application.
5. Every registered user gets the student role by default.
6. Admin and recovery officer roles will be assigned separately.
Important: We'll validate the email domain in JavaScript for user experience and enforce the important checks through Firebase security rules and trusted logic where necessary.
